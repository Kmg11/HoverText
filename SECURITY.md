# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.
Report them privately instead:

- Open a [private vulnerability report](https://github.com/Kmg11/HoverText/security/advisories/new)
  on GitHub, or
- Email the maintainer through the contact links on the
  [landing page](https://Kmg11.github.io/HoverText/).

You'll get an acknowledgement within a few days and updates as the issue is
assessed and fixed. Please include the app version and as much detail as
possible to reproduce the issue.

## Scope

Hover Text is a local, offline Windows app that does not collect, store, or
transmit personal data. Reports about the app itself, its installers, or this
repository are in scope. Dependencies (FlaUI, .NET, Windows) should be
reported to their respective projects.
